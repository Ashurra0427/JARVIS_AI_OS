# ============================================================
# JARVIS AI OS — Requirements
# ============================================================
#
# QUICK INSTALL (recommended — all features):
#   pip install -r requirements.txt
#   playwright install chromium
#
# DEFAULT UI is PySide6 (interface/launch.py, the Qt HUD entry point).
# PyQt6 is kept only for the legacy --legacy-ui path (interface/jarvis_ui.py).
# PyQt6 and PySide6 CANNOT coexist in the same venv —
#   both are listed here for reference; comment out whichever you don't use.
#   There is no jarvis.py in this repo — entry points are server.py (networked
#   brain), main.py (local console REPL), start.py (launcher), and
#   interface/launch.py (Qt HUD).
#
# NOTES:
#   • PyAudio on Windows: pip install PyAudio (pre-built wheel, no compile)
#   • torch is only needed for local Whisper / local embedding models.
#     Skip for cloud-only (Groq STT + Gemini) deployments.
#   • audioop is removed in Python 3.13 — hotword.py and microphone.py
#     use it; stay on Python 3.11 or 3.12.
#   • winsdk is Windows-only and required for media transport controls
#     (play/pause/next/prev). Commented by default — uncomment on Windows.
#   • After `playwright install chromium` you can also run:
#     `playwright install-deps` on Linux to pull system libraries.
# ============================================================
